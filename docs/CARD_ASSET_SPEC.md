# CARD_ASSET_SPEC.md — 카드 에셋 조립 명세

캐릭터 카드에 실제 아트를 얹기 위한 명세.
**좌표는 이 문서가 유일 근거**이며, 전부 `card_frame_character.png`(1000×1528)의 **실측 픽셀값**이다
(프레임 PNG를 스캔해 색상 영역 경계를 검출한 값 — 눈대중 추정 아님).

---

## 1. 에셋 위치

| 종류 | 경로 | 비고 |
|---|---|---|
| 캐릭터 프레임 | `Assets/Art/Frames/card_frame_character.png` | 1000×1528, **중앙 불투명** |
| 캐릭터 일러스트 | `Assets/Art/Illustrations/<카드ID>.png` | 1000×1528, **전면 투명 배경** |
| 폰트 | `Assets/Art/Fonts/KOHINanum_Bold SDF.asset` | TMP Dynamic, SDFAA, 1024² |

⚠️ 일러스트는 현재 **Aggro 덱 10종만** 존재(C05·C07·C14·C15·C22·C30·C31·C39·C41·C42).
MidRange_Blood 10종(C02·C03·C04·C12·C16·C19·C21·C24·C25·C29)은 없다 →
**파일이 없으면 일러스트 레이어를 끄고 프레임+텍스트만 표시**한다. 나중에 PNG만 넣으면 코드 수정 없이 붙는다.

## 2. 레이어 순서

프레임 중앙이 불투명(RGBA `17,27,47,255`)이고 일러스트는 배경이 전부 알파 0이므로:

```
[뒤]  Frame        프레임 전체 (1000×1528)
      Illustration 일러스트 전체 (1000×1528, 같은 사각형에 그대로 겹침)
[앞]  Text…        숫자 · 태그 · 조건/효과 · 이름
```

일러스트는 잘라내거나 스케일하지 않는다 — 프레임과 정확히 같은 사각형에 1:1로 얹는다.

## 3. 좌표 정리표 (1000×1528 기준, 실측)

프레임에 **"체력 / 리치 / 조건 / 효과" 라벨은 이미 그려져 있다.** 코드는 숫자·내용만 얹는다.

| 요소 | left | top | width | height | 정렬 | 바인딩 |
|---|---|---|---|---|---|---|
| **체력 숫자** | 56 | 96 | 182 | 110 | 중앙 | `maxHp` (배틀에선 현재 HP) |
| **리치 숫자** | 762 | 96 | 180 | 110 | 중앙 | `reach` |
| **종족 태그** | 378 | 1011 | 114 | 54 | 중앙 | `race` |
| **무기 태그** | 507 | 1011 | 114 | 54 | 중앙 | `weaponType` |
| **조건 텍스트** | 185 | 1087 | 775 | 56 | 좌·수직중앙 | `effectTiming` |
| **효과 텍스트** | 185 | 1165 | 775 | 120 | 좌·상단 | `effectText` |
| **이름** | 68 | 1300 | 865 | 90 | 중앙 | `name` |

### 실측 근거 (프레임 픽셀 스캔 결과)

```
체력 육각형   x  56~238 (w182)  y  83~275 (h192)   라벨"체력" y 218~243
리치 육각형   x 762~942 (w180)  y  83~275 (h192)   라벨"리치" y 218~243
   → 숫자는 라벨 위 공간(y 83~212)에 배치
구분선 ①      y 983    x 226~776
태그 pill 0   x 378~492 (w114)  y 1011~1065 (h54)
태그 pill 1   x 507~621 (w114)  y 1011~1065 (h54)
조건 칩       x  42~167 (w125)  y 1087~1143 (h56)  라벨"조건" x 74~133
효과 칩       x  42~167 (w125)  y 1165~1221 (h56)  라벨"효과" x 74~135
구분선 ②      y 1290   x  68~933
하단 영역     y 1290~1528 — 완전히 비어 있음
```

조건/효과 텍스트는 칩 **오른쪽**(x 185부터)에서 시작한다. 칩 오른쪽 끝이 167이므로 18px 여백.

> ⚠️ **이름 위치는 유일한 미확정 항목.** 프레임에 이름용 라벨·배경이 없고, 비어 있는 큰 영역은
> 구분선 ② 아래(y 1290~1528)뿐이라 그곳에 배치했다. 아트 의도가 "일러스트 위"라면 이 행만 고치면 된다.

## 4. 표시 크기 환산

카드가 화면에서 W픽셀 폭이면 `배율 = W / 1000`을 모든 좌표·크기·폰트 크기에 곱한다.

| 용도 | 표시 크기 | 배율 |
|---|---|---|
| 배틀 캐릭터 카드 | 126 × 192.5 | 0.126 |
| 밴픽(Ban) 카드 | 118 × 180.3 | 0.118 |
| 밴픽(Pick) 카드 | 150 × 229.2 | 0.150 |

⚠️ **비율 정정**: 실제 에셋은 1000×1528 = **0.6545**다.
`UNITY_BATTLE_UI_SPEC.md` 7번의 "1000×1540 (0.6494)"는 에셋과 어긋나므로 위 높이로 맞춘다
(126×194 → 126×192.5). 안 그러면 일러스트가 세로로 0.8% 늘어난다.
