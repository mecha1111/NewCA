## 1. 게임 개요

캐릭터 덱과 메인 덱을 만들고, 상대와 밴픽을 거친 뒤 4:4 파티 배틀을 하는 카드게임.
자신의 캐릭터 존에 캐릭터 카드가 전부 없어지면 패배.

## 2. 존(Zone) 구성

| 존 | 역할 |
|----|------|
| 캐릭터 존 | 캐릭터 카드 배치. 밴되지 않은 나머지 4장을 겹쳐놓아 HP 표시 |
| 액티브 존 | 액션 페이즈에 사용할 카드를 놓는 존 |
| 코스트 존 | 현재 코스트 표현. 카드를 꺾어(레스트) 사용 여부 판단 |
| 메인덱 존 | 자신의 메인덱 |
| 트래쉬 존 | 버려지거나 사용된 카드 |

## 3. 카드 종류

### 캐릭터 카드
- 구성: 이름 / 무기 / 종족 / HP(최대 15) / 리치(최대 7) / 특성(효과)
- 캐릭터 덱에 들어감 (**캐릭터 덱 = 10장**). 밴픽에서 2장이 밴되어 8장이 남음
- 남은 8장 중 4장을 골라 캐릭터 존에 배치, 나머지 4장은 뒷면으로 놓아 HP 표시

### 메인 카드 (스킬 카드)
- 구성: 이름 / 무기 / 효과 / 속도(스킬 카드)
- 메인 덱에 들어감. 전부 스킬 카드로 구성
- 메인 덱은 총 24장. 중복 카드는 최대 2장까지
- ⚠️ **현재 스타터 덱 데이터는 24장 미달** (Aggro 스킬 18, MidRange 20) = **데이터 미완성**.
  24장 규칙은 확정이며, 스타터 덱 데이터를 나중에 채워야 함. 로더는 미달 시 경고만.
- 메인덱 카드는 코스트로 사용 가능 (코스트존에 뒷면으로 배치, 레스트하여 사용 여부 판단)
- **메인덱 0장이 되면 트래쉬존을 셔플하여 다시 메인덱으로** (단, 챌린지 중에는 아님 — 아래 8번 참고)

### 아이템 카드
- ⚠️ 원본 데이터 미완. 스타터 Aggro 덱에 I13/I14 있으나 데이터 테이블에 없음. **현재 범위 밖.**

## 4. 게임 시작 전

### 밴픽
캐릭터 덱 10장으로 시작. 다음을 2라운드 진행:
1. 서로의 캐릭터 덱을 교환하여 1장을 밴한 후 돌려준다
2. 각자의 덱에서 2장을 선택한다
3. 이 과정을 1번 더 반복한다

**결과**: 각자 밴 2장(라운드당 1장)으로 10 → 8장. 픽으로 고른 4장을 배치하고,
남은 4장은 HP 표시용. (배치 4 + HP 4 = 8, 딱 맞음)

### 세팅
1. 선택한 캐릭터 카드 4장의 순서를 정하고 배치
2. 남은 캐릭터 카드로 HP 표시

### 준비 (멀리건)
1. 덱을 셔플하고 6장을 뽑아 손패에 넣는다
2. 패에서 2장을 골라 코스트존에 배치
3. 듀얼 개시 선언

## 5. 턴 진행 (게임 중)

### 5-1. 드로우 페이즈
- 덱에서 카드 2장 드로우
- 드로우한 카드에서 **최대 2장까지** 코스트존으로 넣을 수 있음
- 코스트존에 놓지 않은 카드는 패로

### 5-2. 레디 페이즈
- 엑셀로 사용할 카드를 선택하여 속도 순서대로 뒷면으로 놓음
- 일반 사용 카드도 선택하여 속도 순서대로 뒷면으로 놓음

### 5-3. 액션 페이즈
1. **엑셀로 지정한 카드**를 한 장씩 뒤집어 **속도 순서대로** 효과 발동
2. 엑셀 처리가 끝나면, 엑셀로 지정하지 않은 카드를 한 장씩 뒤집어 속도 순서대로 발동

### 5-4. 엔드 페이즈
- HP가 0인 캐릭터 카드를 코스트존에 배치
- 자신의 캐릭터 존에 캐릭터 카드가 전부 없어지면 패배

## 6. 카드효과 발동 순서 (액션 페이즈 상세)

1. 각자 엑셀로 지정한 스킬 카드를 뒤집어 속도 순서대로 발동
2. 속도가 빠른 카드의 효과를 먼저 적용
3. 효과 적용이 끝나면 다음 카드 오픈
4. 서로 선택한 스킬 카드가 없어질 때까지 반복
5. 속도가 같을 경우 **챌린지** 상태 (아래 8번)
6. 마지막으로 아이템 카드 효과 적용 (아이템 범위 밖이므로 현재 무시)

## 7. 키워드

### 코스트
- 카드 효과 발동 시 사용. 지불할 코스트가 없으면 그 카드 효과는 **불발**.

### 신속
- 레디 페이즈에 보유한 신속 수만큼 신속 사용 카드 지정 가능
- 신속 카드는 액션 페이즈에 보통 카드보다 먼저 적용
- 아이템도 신속으로 사용 가능
- ⚠️ 스타터 덱에 신속 부여 카드 없음 → 토큰 구조만 유지, 실사용 없음

### 관통
- 상대의 방어도를 무시하고 공격

### 엑셀
- 조건: 발동 중인 카드 속도와 상대 카드 속도가 같으면 챌린지 상태 진입 (8번)

## 8. 챌린지 (속도 동률 시)

진행 방식:
1. 각자 동시에 **덱 탑을 오픈**해서 무기 타입 확인
2. 발동 대상 캐릭터와 그 무기 타입이 같으면 **성공**
3. 서로 성공했으면 다시 덱 탑 오픈 — 둘 중 실패자가 나올 때까지 반복
4. 먼저 **단독 성공**하는 사람만 효과 발동
5. 챌린지 도중 덱이 전부 없어지면 그 사람은 효과 무효 + 상대 자동 성공 (**코스트 반환 없음**)
6. 둘 다 동시에 덱이 없어지면 둘 다 무효

### ✅ 사용자 확정 (설명서 미명시분)
- **공개한 카드는 트래쉬로 간다**
- **양쪽 다 무기 매칭 실패 시 → 양쪽 무효**
- **공용 카드는 무효** (매칭 실패로 처리)
- **챌린지 중에는 트래쉬 재순환 없음** — 덱 0장이면 규칙 5번대로 자동 패배.
  트래쉬→메인덱 셔플은 **드로우 상황에서만** 발생.

| 두손검 | 근접공격, 근접공격 | 느린 속도 |

### skill1/skill2 선택(R14) 상세

두 번째 스킬을 가진 카드는 코스트와 효과가 서로 다른 두 모드다 (예: S84 마지막 저항 —
skill1은 코스트 0, skill2는 코스트 2). 어느 쪽으로 낼지는 **뒷면으로 놓는 레디 페이즈에 확정**한다.

액션 페이즈에 뒤집는 순간 고르게 하면, 상대가 속도 배치로 대응할 여지 없이 정보 비대칭이
지나치게 커지기 때문이다. 낼 때 확정하면 서로 같은 조건에서 속도를 배치할 수 있다.

- 단, 종족 조건 등으로 어느 쪽을 쓸지가 이미 정해지는 카드(S20 잔혹한 운명)는 선택의 여지가 없다.
- 두 번째 스킬이 없는 카드는 항상 skill1.

### 사망 후 위치(R9) 상세 — 앞당김

캐릭터가 사망해 코스트존으로 가면 그 뒤 캐릭터들이 **한 칸씩 앞으로 당겨진다**.
빈자리는 남지 않으며, 살아있는 캐릭터의 Position은 **언제나 0부터 연속**이다.
거리 계산(R4)은 당겨진 뒤의 Position을 쓴다.

```
사망 전: [내3][내2][내1][내0] │ [적0]…
          D    C    B    A

A(Position 0) 사망 후 — 뒤가 전부 한 칸씩 전진:
              [내2][내1][내0] │ [적0]…
               D    C    B     ← B가 0, C가 1, D가 2

B → 적0 거리 = 0+0+1 = 1  (사망 전엔 2였음 — 더 가까워짐)
```

중간이 죽어도 마찬가지로 뒤쪽이 당겨져 빈자리를 메운다.

```
[내2][내1][내0]      C(Position 1) 사망     [내1][내0]
 D    C    B      ──────────────────────►   D    B     ← D가 1로 전진
```

> **이력**: 초기에는 "앞당김 없음(위치 고정)"으로 확정했다가 2026-08-08에 뒤집었다.
> 위치 고정 방식은 양쪽 마지막 생존자들이 서로의 리치 밖에 남아 영원히 공격이 닿지 않는
> **"리치 교착"**을 만들어 게임이 끝나지 않는 문제가 Phase 5 통합 테스트에서 실측으로 드러났다
> (10개 시드 전부 교착 → AI 포메이션 조정 후에도 2개 잔존). 실제 게임 규칙이 앞당김이며,
> 앞당김에서는 생존자가 항상 최전선부터 채워지므로 거리가 계속 줄어들어 교착이 구조적으로 생기지 않는다.

### 동속도 다중 카드(R10) 상세

```
속도 5:  P0 → [카드a][카드b]      P1 → [카드x]

챌린지 ①: a vs x  → 단독 성공자만 발동
b 는 짝 없음 → 챌린지 없이 그대로 발동
```

### 리치(R4) 상세 — 배치 도식

```
[내3][내2][내1][내0] │ [적0][적1][적2][적3]
                     └ 최전선끼리 인접 (거리 1)

거리 = 공격자 Position + 대상 Position + 1
예) 내0 → 적0 = 0+0+1 = 1
    내0 → 적3 = 0+3+1 = 4
    내3 → 적3 = 3+3+1 = 7  (최대)
```

### R9와의 상호작용 — 앞당김이 거리를 계속 좁힌다

R9(앞당김)와 R4(거리 = 위치 합)가 맞물리면, 캐릭터가 죽을수록 남은 생존자가 최전선 쪽으로
당겨지므로 **양쪽 거리가 계속 줄어든다**. 따라서 게임이 진행될수록 공격이 닿기 쉬워지고,
서로 닿지 않아 끝나지 않는 상태는 구조적으로 생기지 않는다.

> 참고: 이전의 "위치 고정" R9에서는 정반대였다 — 앞이 죽어도 뒤가 그대로 남아 거리가 유지되고,
> 마지막 생존자들이 서로의 리치 밖에 갇히는 **리치 교착**이 실측으로 다수 발생했다. R9를 앞당김으로
> 바로잡으면서 해소됐다. 통합 테스트의 최대 턴 안전장치는 그대로 두되(무한 루프 방지용),
> 정상 상황에서는 걸리지 않아야 한다.

Position 0 = 최전선, Position 3 = 최후방.

## 11. ⚠️ 아직 가정 상태인 항목 (저영향, 확정 시 갱신)

이건 확정 안 됐지만 발생 빈도가 낮아 임시 가정으로 진행 중. 사용자 확정 시 이 표를 갱신:

| 항목 | 임시 가정 |
|------|-----------|

### Phase 4에서 카드 원문을 해석한 내역

원문이 불완전해 해석이 필요했던 것들. 확정되면 이 표를 갱신하고 해당 핸들러를 고치면 된다.

| 카드 | 불명확한 점 | 채택한 해석 |
|------|------------|------------|
| S01 치고 빠지기 | "이전에 사용된 스킬" 범위 | **이번 턴 자신이 이미 발동한 스킬**이 있으면 실패 |
| S20 잔혹한 운명 | skill1/skill2 선택 주체 | 사용 캐릭터의 **종족**으로 갈림 (노예→skill1, 추격자→skill2, 그 외 실패) |
| S53 바드의 분노 | "리치 내 캐릭터" 범위 / 버프 대상 | 데미지는 **리치 내 적 전체**, 버프(+2)는 **사용 캐릭터 본인** |
| S55 핏빛 가시 | "가운데/사이드" 정의 | 선택 대상이 가운데, **Position ±1**인 적이 사이드 |
| S57 갈망하는 피 | "턴 종료 시" 예약 | 예약 구조가 없어 **즉시 덤핑**으로 단순화 |
| S78 피의 마도서 | "아군 HP 1회복"의 분배 | R11에 따라 **사용 캐릭터**에게 min(7, 피 카드)만큼 회복 |
| S79 피의 계약 | X코스트 지불량 | `VariableCostPolicy` 델리게이트에 위임 (기본 최대 3) |
| S82 피의 활시위 | "이번 턴 보유 코스트" | **코스트존 총 매수** (레스트 여부 무관 — 이 카드 자신의 지불로 수치가 흔들리지 않게) |
| S84 마지막 저항 | skill1/skill2 두 선택지 + HP 지불이 R11과 충돌 | **skill1**: [아군 전체 HP-3] → 그 후 HP 3 이하가 된 **노예/추격자** 아군에게 이번 턴 데미지 +2. **skill2**: [사용자 HP-1] 카드 2장 드로우. 이 카드의 "HP-3" 비용은 **R11의 예외**로 HP를 **최소 1로 바닥 처리**한다(자멸 없이 항상 발동) — 다른 모든 카드의 HP 비용(PayHp)은 R11대로 자멸 불가·지불 실패가 원칙이며 이 예외는 S84 skill1 한정 (사용자 확정, 2026-08-07) |
| C12 아르케아 | 데미지 대상 | **리치 내 가장 앞선 적** |
| C19 레비아 | 발동 횟수 제한 | **턴 1회** |
| C21 광신도 | 타이밍("카드 스킬 발동 전") / 변환량 | 코스트 확보가 쓸모 있으려면 **레디 페이즈 전**. 변환량은 `VariableCostPolicy` |
| C25 실비아 | "리치 -1, 데미지 +2" 지속 | **게임 중 1회만** 적용되는 영구 보정 |
| C41 리베카 | "리치 내 모든 캐릭터" | RULES 11 가정대로 **아군**. 아군끼리의 거리는 규칙에 정의가 없어 **리치 검사 없이 아군 전체** |
