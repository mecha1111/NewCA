# 카드 UI 수정 명세 (실측 재확정)

기존 CharacterCardView 배치가 어긋난 것을 실측으로 다시 잡음.
프레임 PNG(1000×1528) 픽셀 분석 기준. **축소 표시 시 이 좌표를 카드폭/1000, 카드높이/1528로 비율 환산.**

## 발견된 버그와 원인

| 증상 | 원인 | 수정 |
|---|---|---|
| HP/리치 숫자가 "체력/리치" 글자와 겹침 | 숫자를 육각 중심(y180)에 놓음 → 그 자리에 "체력" 글자(y230)가 있음 | 숫자를 육각 **상단**(y150)으로 |
| 이름이 효과보다 아래 | 이름/효과 y좌표 뒤바뀜 | 이름 y955, 효과 y1210 (아래 표) |
| 색깔 이상 | 텍스트 색 미지정/오지정 | 이름·숫자 흰색(#EEF3FA), 조건/효과 밝은회(#DFE7F2) |
| 비율 왜곡(레베카 등 늘어남) | 카드 높이가 0.6494로 계산됨 | **0.6545 고정**(1000×1528) |

## 정확 좌표표 (1000×1528 기준)

| 요소 | 위치(중심 또는 시작) | 정렬 | 폰트px | 색 | JSON |
|---|---|---|---|---|---|
| 체력 숫자 | (147, 150) | 중앙 | 60 | 흰 | maxHp/현재HP |
| 리치 숫자 | (852, 150) | 중앙 | 60 | 흰 | reach |
| 이름 | (500, 955) | 중앙 | 50 | 흰 | name |
| 직업태그 | (430, 1040) | 중앙 | 30 | 연보라 | (weaponType) |
| 종족태그 | (560, 1040) | 중앙 | 30 | 연보라 | (race) |
| 조건 내용 | (195, 1110) 시작 | 좌 | 30 | 밝은회 | effectText 조건부 |
| 효과 내용 | (195, 1210) 시작 | 좌 | 30 | 밝은회 | effectText |
| 종족/직업(하단) | (500, 1400) | 중앙 | 34 | 회색 | race/weaponType |

**중요**: "체력"·"리치"·"조건"·"효과" 글자는 프레임에 이미 그려져 있음. 코드는 **숫자·내용만** 얹음. 절대 라벨 다시 그리지 말 것.

## 레이어 순서 (뒤→앞, 고정)
```
1. Frame        (프레임, 중앙 불투명)
2. Illustration (일러스트, 있으면. 없으면 레이어 끔)
3. BottomScrim  (하단 스크림)
4. 텍스트 전부  (위 좌표)
```

## 비율 (절대 규칙)
- 1000 × 1528 = **0.6545**
- 카드폭 W면 높이 = W / 0.6545
  - 126 → 192.6
  - 150 → 229.2
- 일러스트도 이 비율로. 늘이거나 왜곡 금지. 프레임과 같은 캔버스에 정렬.

## 축소 환산 예 (카드 표시폭 150일 때)
- 체력숫자 x = 147/1000×150 = 22.05, y = 150/1528×229.2 = 22.5
- 이름 x = 500/1000×150 = 75(중앙), y = 955/1528×229.2 = 143.2
- 효과 y = 1210/1528×229.2 = 181.5
