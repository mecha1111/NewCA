## 확정된 게임 시스템 (프로토타입에서 룰북 대조 완료)

### 밴픽 — 전체 공개 (비밀 폐기됨, 유저 지시)
- 상대 밴/픽 즉시 공개. 카드에 직접 "상대 픽"/"상대 밴" 라벨 표시
- 상호 배제: 상대가 픽한 카드는 내가 밴 불가, 내가 밴한 카드는 상대가 픽 안 함
- 순서: 밴1 → 픽2 → 밴1 → 픽2

### 배치 (신규 화면)
- 픽한 4장을 **카드 클릭 → 슬롯 클릭**으로 P1~P4 배치
- **오른쪽 = P1 = 전방** (전투와 동일 방향). 라벨은 슬롯 바깥 위 (카드 겹침 금지)
- 캔슬: 채운 슬롯 클릭 시 비움

### 리치 / 사망
- 내 전방=우측끝(x960 접점), 상대 전방=좌측(내 화면). 거리 = 내 위치 + 상대 위치 − 1
- **사망 시 전방(접점)으로 당김** (내=오른쪽, 상대=왼쪽) = R9 앞당김과 일치

### 코스트 — 레스트/언탭
- 코스트 = 코스트 존 카드 총량(pool). 사용 시 레스트(꺾음), 소멸 아님. **매 턴 전부 언탭**
- 초기: 손패 6장 중 2장 골라 코스트로 버림
- 매 턴 드로우 후: **방금 뽑은 2장 중에서만** 0~2장 코스트 (기존 손패 불가)
- 사망 캐릭터 → 코스트 존(pool+1)

### 드로우
- **첫 턴도 드로우 페이즈부터** 시작 (초기 코스트 확정 후)
- 매 턴 2장 드로우

### 레디 — 선택+캔슬
- 손패 클릭 → 사용가능 캐릭터 청록 하이라이트(불가 사유 로그) → 캐릭터 클릭
- 공격 && 리치 내 적 2명 이상이면 **타겟 클릭 지정** (1명=자동, 0명=배치되나 불발, 회복=자동 최저HP)
- 캔슬: 배치된 슬롯 hover X → 손패 복귀 + 코스트/신속 환급

### 신속 (Swift)
- 자원은 **특정 캐릭터가 제공** (파티 swift 합 = swiftMax). 매 턴 리셋
- 배치된 스킬 아래 ⚡토글 (자원 소모/환급, 0이면 비활성)
- 발동 순서: [신속 그룹(속도순)] → [일반 그룹(속도순)]

### 액셀 (Accel) — 자동 + 느린 연출
- 유저 지정 없음. **속도 동점(같은 신속 그룹, 다른 진영) 자동 진입**
- 느린 연출: A 덱탑 한 장 공개(0.7s) → 판정(0.9s) → B 공개 → 무기 일치 쪽 선공, 진 쪽 불발. 둘 다 일치 시 재대결 반복
- 엔진 asAccel은 내부용 (UI 토글 아님)

### 아이템 — **폐기됨** (I13/I14 나중에 제거)

### 전투 비주얼
- **점대칭(180도)**: 상대 카드 뒤집음(육각 아래+좌우반전, 이름 위, 스크림 위), 덱 좌상162°↔우하-18°
- 액트존 영역 박스(청록/빨강 발광), **중앙 접점 장식 박스 금지**(유저 제거 지시)
- 캐릭터 150×229, 액트 슬롯 150×150. 열: 내[330,490,650,810] 상대[960,1120,1280,1440]
- Phase 패널(BATTLE 헤더+페이즈 진행바+코스트/신속 pip+로그+입체 버튼)
- 사거리 hover 하이라이트+거리칩, 프리뷰 좌측 패널
